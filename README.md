# Programação de Aplicativos — 2026/1

Repositório de estudos da disciplina de Programação de Aplicativos.

## Organização

Os materiais estão separados por mês e data da aula:

- **Agosto:** exercícios de revisão, métodos e primeiros exemplos de orientação a objetos.
- **Setembro:** exercícios com classes, objetos, métodos, construtores, `toString()` e encapsulamento.
- **Outubro:** `ArrayList`, relacionamento entre objetos e exercícios de modelagem com classes.
- **Novembro:** exercícios com objetos, contas, pessoas, endereços e datas (`LocalDate`).

## Sobre os arquivos

Os arquivos Java que já estavam no repositório foram comparados com o repositório original do professor e correspondem aos materiais disponibilizados na disciplina. Eles foram mantidos como referência, sem serem apresentados como soluções autorais.

## Minhas atividades

As soluções desenvolvidas individualmente devem ser colocadas na pasta **Minhas Atividades**, separadas por mês e exercício. Assim, fica fácil distinguir o material de aula das atividades realizadas pelo estudante.
