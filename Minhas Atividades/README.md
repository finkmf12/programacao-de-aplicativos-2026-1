# Minhas Atividades

Esta pasta é destinada às atividades resolvidas individualmente.

## Como organizar

Crie uma pasta para cada mês e, dentro dela, uma pasta para cada exercício.

Exemplo:

```
Minhas Atividades/
├── Agosto/
│   ├── Exercicio 01/
│   └── Exercicio 02/
├── Setembro/
├── Outubro/
└── Novembro/
```

Adicione aqui somente os códigos que você realmente desenvolveu ou modificou para resolver as atividades. O material original do professor permanece nas pastas da disciplina.
